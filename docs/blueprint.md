# **App Name**: Soma Digital School

## Core Features:

- Intelligent AI Mentor Tool: An AI-powered mentor utilizing Gemini to provide strategic business advice and personalized roadmap adjustments.
- Dynamic Community Feed: A high-fidelity real-time activity stream for community engagement, featuring rich media support and smart filtering.
- Gamified XP & Streak Engine: Drives engagement through animated achievement badges and streak tracking for consistent daily contributions.
- Tiered Access Dashboard: Role-based control center that toggles between Free and Premium views with luxury-tier data visualizations.
- Resource Marketplace: A sleek digital asset gallery for premium funnels, templates, and branding assets managed via a cloud database.
- Automated Onboarding Journey: Interactive cinematic walkthrough that captures user goals to personalize their AI mentorship profile.
- Global Live Notifications: Subtle, non-intrusive notification system for mentions, unlocks, and direct community alerts.

## Style Guidelines:

- Primary Color: Electric Blue (#1A66FF) - a vibrant, high-energy hue that signifies tech-forward luxury.
- Background Color: Obsidian Charcoal (#0A0B0E) - a deeply desaturated dark tone with a subtle hint of blue for a premium look.
- Accent Color: Cyan Glow (#00B2D9) - an analogous cool tone for high-contrast interactive elements and hover effects.
- Headline Font: 'Space Grotesk' (Sans-serif) for a bold, technical, and high-fashion digital feel. Body Font: 'Inter' (Sans-serif) for ultimate readability and objective professional aesthetics.
- Minimalist line icons with soft 'purple ambient' glow effects and glassmorphic backgrounds for a floating, futuristic look.
- Clean, spacious mobile-first grid with subtle glassmorphism containers and wide, cinematic margins inspired by Apple and Stripe.
- Fluid page transitions with Framer Motion, featuring floating gradient particles and smooth hover expansions for interactive cards.
