# Coding Standards

Use TypeScript.

Use strict typing.

Avoid any.

Create reusable components.

Keep functions small.

Maximum function length: 60 lines where practical.

Maximum file size: 500 lines before considering refactoring.

Prefer composition.

Avoid duplication.

Follow SOLID.

Write tests.

Write documentation.

Use logging.

Handle errors.

Never hardcode configuration.

Use dependency injection where appropriate.

Never expose secrets.

Always validate inputs.

Always sanitize outputs.
