# Canonical Rules

There must only be one implementation of every system.

PromptOS owns prompts.

AgentOS owns agents.

Gateway owns providers.

Credits own AI billing.

Subscriptions own permissions.

Knowledge Engine owns retrieval.

Memory Engine owns conversations.

Marketplace owns products.

Community owns social interactions.

Business Engine owns analytics.

Never create duplicate systems.

Always reuse existing code.

Always extend existing architecture.

Never bypass security.

Never bypass the AI Gateway.

Never bypass the Credit Engine.

Never bypass authentication.

Every new feature must integrate into the existing architecture.

The architecture documents are the single source of truth.
