# Soma Digital Community Engineering Rules

You are assisting with the Soma Digital Community (SDC).

Project Stack

- Next.js 15 App Router
- React 19
- TypeScript
- Firebase Auth
- Firestore
- Firebase Storage
- Cloud Functions
- Paystack
- Tailwind CSS
- Framer Motion

Coding Standards

- Never use any.
- Prefer strict TypeScript.
- Keep components small.
- Reuse components before creating new ones.
- Prefer server components where possible.
- Client components only when necessary.
- Follow existing project architecture.

When writing code

- Explain your reasoning first.
- Then provide code.
- Preserve existing functionality.
- Never remove features unless asked.
- Always consider performance.
- Avoid unnecessary re-renders.
- Handle loading and error states.

Firestore

- Minimize reads.
- Batch writes when possible.
- Use indexes correctly.
- Never expose admin credentials.

Authentication

- Use Firebase Auth.
- Protect server actions.
- Validate user permissions.

UI

- Responsive by default.
- Mobile-first.
- Accessible.
- Clean modern design.

Testing

Before finishing:

- Check TypeScript.
- Check imports.
- Check lint issues.
- Check edge cases.

If unsure, ask before making breaking architectural decisions.
